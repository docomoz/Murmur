# Murmur Privacy Policy

_Last updated: October 15, 2026_

Murmur sends anonymous usage statistics so we can see how the app is used and make it better. Nothing in them identifies you.

- **What is sent:** which features are used (mixes, Shuffle, the Pomodoro timer, Shortcuts actions, settings like the theme), which sounds are played and for how long, the app and macOS version, the Mac model and screen size, the system language, region and time zone setting.
- **How it stays anonymous:** the statistics go to [TelemetryDeck](https://telemetrydeck.com), a privacy-focused analytics service. Each copy of the app has a random identifier that is hashed before it leaves your Mac and hashed again on TelemetryDeck's servers; TelemetryDeck doesn't store IP addresses. The data isn't linked to you and isn't used for tracking or advertising.
- **What is never sent:** the names of your mixes, anything about other apps, files, your name, email or account — Murmur has no accounts.
- There are no ads and no tracking.
- Your settings — volumes, saved mixes, theme, backdrop, accent color — stay on your Mac in the standard macOS preferences storage and are removed together with the app.
- The version downloaded from GitHub also checks for updates: it reads the update feed on GitHub and downloads new versions from GitHub Releases.
- The GitHub link in the About window opens in your browser; GitHub's own privacy policy applies there.

Questions: use the [support page](https://github.com/docomoz/Murmur/issues).

# Политика конфиденциальности Murmur

_Последнее обновление: 15 октября 2026 г._

Murmur отправляет анонимную статистику использования — чтобы понимать, как пользуются приложением, и делать его лучше. По ней нельзя узнать, кто вы.

- **Что отправляется:** какие функции используются (миксы, «Наугад», помодоро-таймер, действия «Быстрых команд», настройки вроде темы), какие звуки играют и сколько времени, версия приложения и macOS, модель Mac и размер экрана, язык, регион и часовой пояс из настроек системы.
- **Почему это анонимно:** статистика уходит в [TelemetryDeck](https://telemetrydeck.com) — сервис аналитики, построенный вокруг приватности. У каждой копии приложения есть случайный идентификатор; он хешируется ещё на вашем Mac и повторно на серверах TelemetryDeck, IP-адреса TelemetryDeck не хранит. Данные не связаны с вами и не используются для трекинга или рекламы.
- **Что не отправляется никогда:** названия ваших миксов, сведения о других приложениях, файлы, ваше имя, почта или аккаунт — аккаунтов в Murmur нет.
- В приложении нет рекламы и трекинга.
- Ваши настройки — громкости, сохранённые миксы, тема, подложка, акцентный цвет — хранятся только на вашем Mac, в стандартном хранилище настроек macOS, и удаляются вместе с приложением.
- Версия, скачанная с GitHub, ещё проверяет обновления: читает ленту обновлений на GitHub и скачивает новые версии из GitHub Releases.
- Ссылка на GitHub в окне «О программе» открывается в вашем браузере; на сайте GitHub действует политика конфиденциальности GitHub.

Вопросы — через [страницу поддержки](https://github.com/docomoz/Murmur/issues).
